# SLATE-REBUILD

SLATE, an actor/actress life simulator, rebuilt layer by layer from the first SLATE (`montrealroots/1221`) and
SLATE (`montrealroots/SLATE`). Start with `CLAUDE.md` (the rules: 1221's, then SLATE's), then `HANDOFF.md` for where
the build stands.

## Running it

Node 22.23.4 (`.nvmrc`). Install with `npx -y npm@11.6.2 ci` (npm is pinned in `packageManager`; the lockfile is
kept with npm 11.6.2). Add a dependency at an exact version: `npm install -E <package>@<version>`.

- `npm run gate`: the gate, as every commit runs it (`.githooks/pre-commit`): the toolchain pins, the owner's
  documents, the build order, the text inventory, Title Case, the catalog's words, the research register, the
  typecheck, the lint, the tests, the feature-to-effect matrix, the engines' effects, the coverage matrices, the
  handoff and the files the docs name.
  Exit 0 green, 1 red (a rule broken), 2 incomplete (declared work unfinished). Read the exit code from a file, never
  through a pipe (`CLAUDE.md`, Part 1).
- `npm run gate:full`: the same plus `npm audit` (any known advisory is red) and mutation testing at a 100% break
  threshold; a layer is proven only on a green full gate. CI runs it on every push (`.github/workflows/gate.yml`).
- `npm run gate:write`: rewrites the generated matrices in `matrix/` from what the checks find.
- `npm run lock:owner-docs`: re-locks the owner's documents; only with a change the owner made.

## Where things are

| Path | What |
|---|---|
| `CLAUDE.md`, `docs/` | The owner's documents: the rules, 1221's style and glossary, the kept tokens. Locked. |
| `gate/` | The gate: its checks, its lint rules, its tests. |
| `registry/` | What the gate holds the build to: layers, pages, features, effects, engines, axes, the voice rules. |
| `research/register.json` | The research register: every fact, its source and the date it was read, or its blocker. |
| `coverage/` | One coverage matrix per engine axis, from layer 1. |
| `matrix/` | Generated by the gate for reading: layers, features, effects, coverage, the register in brief. |
| `src/` | The game, by layer, from layer 1: `core`, `world`, `papers` and `money`, `person`, `ui` and `app`. |
| `workbench/plans/` | SLATE's layer 4 plans, as SLATE wrote them, which layer 4's code names: the attribute map its test holds each role's attributes to, the identity plan, the screenwriter's attributes. |
| `tests/` | The game's tests; `tests/support/falsify.ts` records each falsifiability proof for the gate. |
| `tools/setup/` | The development tools for cloud sessions, and `verify.sh` to check them. |
